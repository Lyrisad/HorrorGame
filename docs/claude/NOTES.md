# Technical notes (Claude's project memory)

Durable knowledge gathered while building the game: architecture, pipelines, test flags, gotchas.
Keep it current — add a line whenever you learn something non-obvious. History of requests: HISTORIQUE.md.

## Architecture
- Godot 4.7.2, GDScript, Forward+. Export → `build/DernierEnregistrement.exe` (~1 GB, everything embedded).
- Levels are generated by code (no editable .tscn): `scripts/levels/night.gd` (drive + house in ONE continuous
  world, house 1000 m along the road), `sewer.gd` (3 construction eras by column: brick vaults / concrete
  reservoir / tiled service galleries; continuous water channel network, wall pipes, blind sound-hunting
  creature), `ending.gd` (night forest surface: hut, kidnappers' camp, hunters, drone, pole camera). Autoloads: Game, Sound, …; `B` = builder helpers,
  `HouseBuilder`, `Nature` (trees, rain, dust, flies, steam, leaves), `Props`.
- User-placeable decor = in-game map editor (F8 / main menu "Éditeur de cartes", `scripts/core/map_editor.gd`)
  + MapLayout JSON: `user://cartes/<maison|egouts>.json` overrides `res://maps/` (shipped defaults).
  Decor placed via HouseBuilder.deco()/deco_on()/deco_cup() and sewer.deco() is skipped when a layout exists;
  story objects stay put()/fixed. B.model stores a "spec" meta to recreate any model. Story objects movable
  in the editor use meta "editobj" (saved under "objs"): laptop, bathmat, sewer lamp_b0..4/lamp_red/lamp_gate
  (their lights are children) — movable, not deletable.
- **The user's own layouts** live in `%APPDATA%\Godot\app_userdata\Dernier Enregistrement\cartes\` and are copied
  into `maps/`. Back them up before any editor test (--edtest/--edcam/--edlap/--edclick SAVE), restore + md5-check after.

## Assets & pipelines
- Realistic assets only: Poly Haven (CC0), Sketchfab CC-BY (`assets/sketchfab`, `sf:<name>` in B.model; credit
  every model in CREDITS.md), Microsoft Rocketbox humans (MIT), CMU mocap BVH (`tools/mocap/cmu`).
  Sketchfab download: `SKETCHFAB_TOKEN=<token> python tools/dev/sf_download.py assets/sketchfab uid:name` —
  the token is NEVER written to a file (public repo). Search: `tools/dev/sf_search.py`. Poly Haven: `ph_download.py`.
- Creature = "The Rake" (Sketchfab CC-BY) with its OWN animations, prepared by `prepare_native.py` (scale, bone
  renames Hips/Neck/Head, every bone baked per frame from the "ref" pose because the gallop doesn't animate the
  pelvis, measured ground speed). Actor reads clip speeds from `<char>.anims.json`. Human mocap on non-human
  meshes looked goofy.
- Characters: `tools/blender_scripts/build_characters.py` → Blender `retarget.py` (needs `tools/blender/`, and
  `tools/rocketbox_src/` from `tools/dev/rb_download.py`). Clip options: start/end (source frames), inplace,
  loop, `face_at`, `ref:"facing"`, `yaw`. After rebuilding run `--headless --import` (render tools hang otherwise).
- Retarget gotchas: find the loop point BEFORE measuring travel/speed; CMU BVH frame 0 is a calibration T-pose
  (start ≥ 2); non-locomotion clips use average body facing; alignment must use the SAME reference child on both
  rigs (PREF_CHILD: pelvis→spine, upper spine→neck) or the torso twists. Corpses: static frames of 90_16 /
  140_03 placed with Actor.lowest_point() (CPU skinning).
- Blender helper scripts: split_camera.py (security camera → fixed mount + rotating head), split_fusebox.py
  (fusebox with empty "Socket_1..3", fuse exported as sf:fuse_screw).
- Sounds: `tools/audio_gen/generate_sounds.py` (+ `extra_sounds.py` regenerates a few) → `assets/audio`.
  Generate a single sound: `import generate_sounds as g; g.write('name', g.name(), gain)` with
  `sys.argv=['x', '<repo>/assets/audio']`. New audio files need `--headless --import` before `Sound.stream()`
  finds them (otherwise play_at errors out).
- Textures: `tools/texture_gen/*` (UI textures, sewer decals, icons via generate_icons.py → assets/gen/icon_*.png,
  Material Icons Apache 2.0). After new textures run `tools/fix_imports.ps1` then reimport.

## Rendering / engine gotchas
- MICRO-FREEZES (user: "freeze quand un script se lance, le mec pop"): anything drawn for the first time compiles
  its shaders/pipelines → 50-150 ms hitch (kidnapper appearing, creature reveal, first roach, first dust puff,
  creature entering a shadowed lamp). Fix = Level.prewarm(), run by Game.start_level behind ui.set_cover(true) with
  the tree PAUSED: a temp 120° camera at Théo's head (or the active camera: car, ending) renders 6 directions (no
  occlusion culling → the whole level), then every node of level.prewarm_extras() is moved in front of it under a
  temp shadowed omni + spot (2 frames) and put back. Nodes with meta "prewarm_temp" are created just for this and
  freed, BUT their materials/meshes go to _prewarm_keep (Godot frees a compiled shader as soon as no material uses
  it → it would recompile at the event). sewer: all Actors, creature, a Roach (+ keeps cockroach.glb loaded), dust
  puff/trickle, sparks, 4 rubble materials, a cobweb. night: the kidnapper is created HIDDEN (process disabled) at
  load and reused by _office_scene (no instantiation at the event), plus the creature. ~0.5-1 s extra loading.
  Effects' timers use _after(sec, node, f) (weakref) so freeing an effect early doesn't spam "Lambda capture freed".
  Measure with `--hitch` (prints frames > 40 ms with process/render times, and the prewarm span); `--noprewarm`
  to compare. Screenshots (--shots) themselves cause ~120 ms hitches; rare ~100 ms idle hitches with low
  process/render time are system-side (not events).
- B.local_aabb is exact (vertex-based when a node has non-axis-aligned rotation, cached) — inflated AABBs made
  props float. HouseBuilder `put_on()/rest()` props are raycast onto `support()` furniture trimeshes in `settle()`.
- B._template must clear `scene_file_path` after _clear_owner, otherwise duplicate() re-instantiates AND copies
  unowned children (every model twice).
- Never mix indexed (append_from) and add_vertex in one SurfaceTool. Sewer quads get EXPLICIT normals
  (generate_normals averaged perpendicular faces → stretched triplanar textures).
- StandardMaterial3D emission ADDS emission color + texture: use emission = BLACK with an emission_texture.
- Vector2/Vector3 components are float32: never compare them with ==/!= to a float constant.
- B.spot pointing straight down: give look_at target a small offset (0.3, 0, 0.2).
- SecurityFeed renders at 12 fps with a stripped Environment (house 38→90 fps at 1080p).
- GPUParticles one-shot bursts were unreliable/invisible here; for a handful of objects use tweened meshes
  (Nature.leaves).
- Public repo hygiene: before committing, grep the staged files for the Windows user name / `Users\` paths
  (a plain path regex misses JSON-escaped `C:\\Users\\...`). Generated tools/blender_scripts/cfg_*.json hold
  absolute paths: git-ignored.
- Don't round-trip French files through PowerShell 5.1 Get-Content/Set-Content (mangles UTF-8). Write .ps1 in ASCII.
- In Git Bash never call bare `python` (Windows Store stub hangs) — use a venv python. Write patch scripts to a
  file and run them (bash heredocs containing apostrophes inside python heredocs broke).

## Gameplay systems
- House: blackout only after ALL clues (HOUSE_CLUES: note, tv, laptop, phones, office_door, back_door); Théo hints
  after 50 s idle. UI.blocks_interaction() stops the E that closes a document from re-opening it. TV starts OFF
  and turns on by itself near it; _update_feed keeps the current cam while it films the player's room.
  Porch = 2 visual steps + invisible ramp collider.
- Inventory: InventoryUI (`scripts/core/inventory_ui.gd`, [I], pauses the tree) reads Level.inventory() and
  Level.documents (filled by Level.read_document(title, text, style) — use it instead of Game.ui.show_document).
  Game.hud.pickup(name) = "+ item" toast.
- Sewer: starts locked in a cage (CELL tile (1,2): torch through bars → loose bar → hook keys → padlock). Gate needs
  the chain cut (bolt cutters) AND power (3 fuses: Bertrand (5,13), cistern pillar footing, Karim (14,11) → panel
  next to the gate, model sf:fusebox_vintage, fuses screw into sockets). Picking the cutters drops a bucket →
  checkpoint "bench" (kept for good) + creature.charge() from CHASE_FROM (19,7); dying → retake cutters and redo
  the chase. Throwable bottles (G / right click) = lure noise (creature.hear(..., lure=true)). Creature winded
  after 8 s gallop, wall-occluded hearing, pillar avoidance via nav.obstacles(). Heartbeat: _chase_heat decays
  over 12 s. Exhausted panting is a noise.
- Sewer geometry: rounded inside/outside corners + floor coves (`_wall_rounded`, `_fillets`, `_arc_wall`), NO
  ceiling haunches (user found them ugly); coves interrupted under SERVICE_DOORS. Decals must sit below/above
  wall pipes (zone A pipe 1.38, B 1.26/1.62, C cables 2.2–2.46). Cell bars on BARS_LAYER; Interactable.disable()
  clears collision_layer — restore it when re-enabling.
- Sewer ambience: flies over bodies (Nature.flies + flies_loop), steam leak on the east pipe at STEAM_TILE (19,8)
  (Nature.steam, muffles player noise within 4.5 m), forest gusts at the shafts every 35–80 s (`_forest_gust`:
  wind_gust / owl_hoot sounds, Nature.leaves, moon spot sways). The sewers are under a FOREST, not a city:
  no traffic/urban sounds. SHAFTS (9,8) and (2,5); shaft (9,8) centre = (26.6, 23.8).
- `floor_y()` returns the channel BOTTOM (-0.2) in water; use `maxf(floor_y(p), WATER_Y)` for things resting on
  the surface.
- Real microphone: Sound measures only the mic LEVEL (bus "Mic" + AudioEffectCapture, bus at -80 dB,
  `audio/driver/enable_input=true`); Sound.mic_voice 0..1 above an adaptive noise floor → level.on_noise radius
  3–24 m; HUD MIC meter = real mic only ("MIC OFF" when inactive). Settings: mic on/off, sensitivity, device picker
  + live test bar. The user's main PC uses a virtual mic with a noise gate (pure digital zeros when silent).
  `tools/mic_diag.tscn` = level-only diagnostic. ALWAYS pass --nomic in automated runs.
- SecurityCamera: mount (fixed bracket, oriented by mount_out) + head (pivot at swivel). Cams saved with "wall";
  old saves derive it from dir. Frame posts/beams have NO collision → never rely on raycasts for user-placed cams.
  Ending pole camera is attached explicitly on the pole (two collars). _find_wall skips surfaces in front of the lens.
- Flashlight energy 4.2, fog energy 1.0. The hand AIMS at what the camera looks at (aim_ray, converging
  distance) so the beam centre falls on the screen centre. Head bob = soft "U" (y = sin²), footsteps fire at
  each low point of the bob. Hands tremble ~6 s once danger drops after > 0.65; random flashlight
  glitch every 80–170 s (flicker + flashlight_tap sound).
- Bodycam shader (shaders/bodycam.gdshader): aberration 0.012, grain 0.04 (sewer 0.06) half-res-blended
  so it isn't "snow", dark-area 8 px macroblocks (`compress`), `lens_fog` / `lens_drops` (Game.lens_fog(),
  Game.lens_splash(); drops texture from tools/texture_gen/generate_lens_fx.py). Blurs use the screen
  texture MIPMAPS (`filter_linear_mipmap` + textureLod) — a few offset taps made ghost/double images that the
  user called the "drunk" effect. Lens flares = halo + thin horizontal streak only (NO ghosts, NO star: user
  hated the doubling), from REAL lamps registered with Game.add_flare(light, strength, size): Game projects
  them, raycasts occlusion, passes the 4 strongest as `flare_src[4]`/`flare_col[4]`. The lens crack was
  removed (user didn't like it).
- HUD.say kills the previous subtitle fade tween: before, a line said < 0.4 s after the previous one ended
  was faded to invisible (whole conversations "stopped" mid-way).
- User LOVES the recorded footsteps. Water steps must be WADING (342932 "Wading in Shallow Water"), not
  puddle slaps — the first puddle recordings were rejected; avoid very bright sources (centroid ~8 kHz).
- Sounds: footsteps (concrete, wood, gravel, grass, water, glass), rats and the flies loop are REAL CC0
  Freesound recordings (tools/dev/fs_fetch.py downloads HQ previews by search; tools/audio_gen/real_sounds.py
  slices each step on its impact, scores cleanliness, normalizes). generate_sounds.py no longer writes those
  names. I can't listen: pick sources by SNR / waveform plots, prefer most-downloaded.
- Flashlight energy 3.0, range 22; glitch types: stutter, brownout (_dim_t), blinks, violent 1 s blackout
  (_lamp_off). Creature `_ground()`: the native "run" gallop keeps every hand/foot 30-50 cm above the origin
  for most of its 0.63 s cycle (it LEAPS). A slow min-over-0.5 s offset wasn't enough (user: "still doesn't

  vertex heights) so the torso, not a protruding hand, rests on the floor. Flies = GPU particles with

  grime, algae band at the waterline, wet glossy base) via sewer._wet_concrete(water_y, algae_h, submerged).

  the floor beside the hips; the NPC talk is a kneeling close-up cinematic (control locked ~32 s).

  static frame 500 of CMU 140_04 + BreathModifier/TwitchModifier) at NPC_POS right outside the cage — talks
